# Running commands: background

Moved out of `CLAUDE.md` so it is read only when needed. `CLAUDE.md` keeps the summary and the hard rules.

- Node comes from nvm (`.nvmrc`) and pnpm from corepack (`packageManager` in `package.json`); there's no system Node. Run node/pnpm through `scripts/agent-run.sh <command>` (e.g. `scripts/agent-run.sh pnpm check`), which uses a zsh login shell so nvm loads and picks the project's version, and drops that shell's startup noise. On the user's fish machine (CachyOS), nvm is the pacman package, `~/.zshrc` sources `/usr/share/nvm/init-nvm.sh` for agent shells, and fish uses an `nvm` function via `bass` plus a `conf.d` hook that runs `nvm use default` at startup.
- Staying on Node and pnpm, not Bun: a spike (2026-09-29) found Bun can't read pnpm 12's lockfile, `nuxt build` ran slower under Bun than Node on the same packages (~43 s vs ~32 s), and the built server showed no runtime gain for this database-bound app; Vercel's Bun runtime is also still beta.
- pnpm keeps its default symlinked `node_modules`. The hoisted layout (`nodeLinker: hoisted`) cut local builds from ~55 s to ~32 s, but Vercel's install then fails ("the installed pnpm wrapper is missing" while its pnpm switches to the `packageManager` version), so it was dropped. An untried fix is Vercel's `ENABLE_EXPERIMENTAL_COREPACK=1`; the ESLint rule `import/no-extraneous-dependencies` (on since #45, checks `package.json`, not `node_modules`) would keep catching undeclared imports under a hoisted layout.
- Cloud sessions: a fresh clone has no `.env.local` (it's gitignored and holds live secrets), so anything that needs the database (dev server, `pnpm db:*`, `pnpm admin:set`, API checks) won't work until the environment provides `DATABASE_URL` and `BETTER_AUTH_SECRET`; typecheck, lint, tests, and template compilation work without them.
- Browser checks: Chromium's headless shell is installed in Playwright's cache, `~/.cache/ms-playwright`, which persists across sessions (installed 2026-09-30 for Playwright 1.63 on the user's CachyOS machine; the Mac has Google Chrome instead, `channel: "chrome"`). Install `playwright-core` in the session's scratchpad (`npm i playwright-core`), run scripts with `NODE_PATH=<scratchpad>/node_modules`, and `chromium.launch()` finds the cached browser; if a newer `playwright-core` wants another browser revision, run `npx playwright-core install chromium-headless-shell` again. Scratchpad scripts reach project packages (e.g. `pg`) with `createRequire("<repo>/package.json")`. Use `withSmokeUser` from `scripts/smoke-session.mjs` for throwaway `claude-smoke-*@example.invalid` users: it registers, signs in, hands you the session cookie, and deletes the user afterwards (run with `node --env-file=.env.local`); delete only users you created. Listen for console errors: Vue hydration mismatches only show there.
